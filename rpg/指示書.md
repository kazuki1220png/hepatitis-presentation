# 指示書（次に作業する人／モデルへ）

**「盗賊退治の3DフィールドのRPG作って」の一行だけで制作が回る**状態を作る。
そのために、毎回変わらない「生産の仕組み」を固定し、**お題（テーマ）だけを差し替えられる**ようにする。

作業モデルはClaude／GPT系どちらでも可。まず [00_根本企画書.md](./00_根本企画書.md)・
[README.md](./README.md)・[生産パイプライン.md](./生産パイプライン.md) を開いてから始める。

## 2つのレイヤーで考える

### A. 固定レイヤー（毎回同じ）→ [生産パイプライン.md](./生産パイプライン.md)
3Dフィールド生成アセット・素材ストック・BGM生成（Suno＋Computer Use）など、
**お題が変わっても使い回す道具と手順**。ここを厚くするほど一行指示で回るようになる。

### B. 可変レイヤー（お題ごとに変わる）
お題（例：盗賊退治）と、それを各班へ落とし込んだ中身。

---

## 一行のお題を展開する手順

1. お題を**ジャンルの型**に当てはめる（下の「退治もの」テンプレ参照）。
2. 型から各班ファイル（UI/マップ/バトル/シナリオ/システム）へ落とす。
3. [生産パイプライン.md](./生産パイプライン.md) の手順で、フィールド生成・素材配置・BGM生成を回す。
4. 実機で確認 → 詰まった点を各班ファイルと**この指示書に反映**（build → fix → 指示書更新のループ）。

### ジャンルの型：「〇〇退治」もの（再利用可）

| 要素 | 中身 | 担当班 |
|------|------|--------|
| 討伐対象 | 誰を退治するか（例：盗賊団） | シナリオ |
| 脅威 | なぜ退治が必要か（村・街道が襲われている等） | シナリオ |
| 敵拠点 | アジト＝マップの最終エリア | マップ |
| 首領（ボス） | 最終戦の相手 | バトル |
| 段階的な強敵 | 雑魚→幹部→首領 の難易度カーブ | バトル / システム |
| 依頼者・動機 | 主人公が退治に向かう理由 | シナリオ |
