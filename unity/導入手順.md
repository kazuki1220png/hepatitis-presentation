# Unity導入手順 — 毒消し草クエスト（動く見本）

親：[../rpg/指示書.md](../rpg/指示書.md)

このフォルダの `DokukeshiQuest.cs` は、**Unity単体で動く3D RPGの見本**です。
まず「ゲームの仕組み（移動・クエスト・フィールド切替）」が動くことを確認するためのもの。
見た目は箱の仮組みなので、あとで**あなたのアセットに差し替えて"きれい"にしていきます**（下記）。

## 動かす手順（3分）

1. Unityでプロジェクトを開く（URP・3Dどれでも可）
2. `DokukeshiQuest.cs` を **Assets フォルダにドラッグ**して入れる
3. Hierarchyで右クリック → **Create Empty**（空のオブジェクトを1つ作る）
4. その空オブジェクトに `DokukeshiQuest.cs` を**ドラッグしてアタッチ**
5. **再生（▶）** を押す

操作：**W/S** 前後　**A/D** 旋回　**E** 話す・調べる　**R** リセット

## 動かないときだけ確認

- **キャラが動かない** → `Edit > Project Settings > Player > Active Input Handling` を
  **「Both」** にして再生し直す（新Input System設定のプロジェクト対策）。
- **色が変（真っ黒/真っ白）** → URPスクリプトなら通常は出ます。出ない場合はレンダーパイプライン設定を確認。

## この見本を「きれいな3D」にしていく道すじ

見本は、後からアセットに差し替えられるよう**差し替えポイント**を決めてあります。

| 仮組み（今） | 差し替え先（あなたのアセット） |
|--------------|--------------------------------|
| `BuildTown()` の箱の町 | 3Dフィールド生成アセットで作った**町フィールドのPrefab** |
| `BuildCave()` の箱の洞窟 | 洞窟フィールドのPrefab |
| `BuildPlayer()` のカプセル | Aポーズ→Meshyで作った**キャラのリギング済みモデル** |
| NPC/毒消し草の箱 | キャラ・アイテムのモデル |
| クエスト・移動・フィールド切替のコード | **そのまま流用**（ここが仕組みの本体） |

つまり「**仕組みはコードが担当／見た目はアセットが担当**」に分けてあります。
きれいにする作業＝箱を消して、同じ位置にPrefabを置くだけ。座標（町の洞口・洞窟の入口・NPC・毒消し草）はコード上部に定数でまとまっています。

次段階：この差し替え手順を、指示書の「生産パイプライン」に正式な工程として書き起こします。
