# アムウェイ鍋 手書きレシピメモ（テキスト化＋イラスト化プロンプト）

手書きメモ4枚を書き起こしたものです。アムウェイのクィーンクックウェア／インダクションレンジを使ったレシピです。

- 判読が難しかった箇所は「（?）」を付けています。
- 「IR」「インダクション」はアムウェイのインダクションレンジ（加熱レベル 1〜10）を指します。
- 「ラオック」は原文のまま記載しています（アムウェイのウォック＝中華鍋型の鍋と思われます）。
- 各レシピの末尾に、GPT（画像生成）へそのまま貼れるイラスト化プロンプトを付けています。

## 4. 10分おかず（大フライパン＋万能カップ）

- **〈焼きもの〉** ウインナー、鮭（下味をつけておく?）

```
描く要素：
```

## 12. パエリア（ラオック）

### 材料
- 米 2カップ
- にんにく 1片
- とりもも肉 100g（一口大）
- 玉ねぎ 半分（スライス）
- 水 2カップ
- サフラン 1つまみ（水に入れて色をつけておく。ドリンクガードでもOK?）
- コンソメ 2個
- いか 1杯
- えび 8尾
- あさり 適量
- オリーブオイル 適量

### 作り方
1. ラオック（ウォック）を温めて、オリーブオイルでにんにくを炒める。
2. 材料をぜんぶ炒める。
3. サフランで色をつけた水を入れる。
4. IR レベル10 → カタカタしたら レベル3 で 15分くらい。
5. 火を止めて 10分 むらす。

### イラスト化プロンプト
```
手書きレシピノート風のやさしい水彩イラストを描いてください。

描く要素：
1) ウォックでにんにくと玉ねぎ、とり肉を炒めているところ
2) 米といか・えび・あさりを加えて炒めているところ
3) サフランで黄色く色づいた水を注いでいるところ
4) ふたをして蒸らしたあとの、えび・いか・あさりが並んだ黄色いパエリアの完成
```
