# 解説動画 台本の心理設計テンプレート（generate_lecture_script.py 用）

VPS側 `generate_lecture_script.py` の台本生成プロンプトに、下の「プロンプト追記ブロック」を
そのまま貼り付けて使う。シーン名（tsukami / toc / honpen / ending）とファイル名規則は変えない。
参考実装: `generate_all_tokutei_copd_cevio.py`（tokutei_copd）

---

## 1. 設計思想（なぜこの構造か）

| 要素 | 狙い | 置く場所 |
|---|---|---|
| 一言目で気持ちよく | 最初の数秒で警戒を解き「聞く価値がある」モードに切り替える（初頭効果） | tsukami_01 の第一声 |
| 視聴者が大好き | 好意は返ってくる（返報性）。一対一で話す | 全編「あなた」呼び、各章に敬意を1回 |
| 行動を褒める | 才能や外見ではなく本人が選んだ行動を褒めると再現される | 開いた・見続けた・記録した・気づいた |
| 進捗の承認 | 「ここまで来た」を可視化して離脱を防ぐ | 各章の summary |
| 誰でも知っている例え | 相手の頭にある地図に乗せる | honpen の核心説明に必ず1つ |
| マダンテを打たない | 全部出さず、次回の引きを残す | 最後の実践1つを「これだけ」に絞る |
| CTAは相手の利益 | 登録・高評価の理由を視聴者側の得に置く | ending_06 |
| 約束は必ず回収 | 冒頭のチラ見せは本編で必ず答える。裏切ると信頼が最後に崩れる | tsukami_03 ↔ honpen3 末尾 |

## 2. 量の目安（やりすぎ防止）

- 褒めは10分動画で **4〜5回まで**。毎行褒めると薄っぺらくなり逆効果。
- 第一声の承認は **1文、3秒以内**。承認が長いとYouTubeの冒頭離脱で本題に届かない。
- 褒める対象は必ず **具体的な行動**（「あなたは素晴らしい」は禁止）。
- 例え話は **1シーンに1つ**。混ぜると地図が二重になる。
- 「あなた」呼びは自然な位置だけ。全文に入れない。

## 3. シーン別ルール

### tsukami（つかみ）4本
1. `intro_impact`: 【承認1文】→【衝撃の一言】。順番は固定。承認は「この動画を開いた」「調べに来た」という行動を指す。
2. `merit`: 今日持ち帰れる価値を1文で。「専門用語ゼロ」を明言。
3. `chirami`: 最後に教える「たった1つ」を予告する。**本編で必ず回収する**（レビュー必須項目）。
4. `warmup`: キャラの緩み。最後に視聴者への一言を添えてもよい（例:「あなたもたまには吐き出して」）。

### toc（目次）4本
- `toc_intro` で「3つだけ」＋「忙しいあなたでも持ち帰れる」と数を約束する。
- `toc_one` で例え話の予告（「台所にあるもので」など、素材の出どころを示す）。

### honpen（本編）各章 7〜9本
- 章の2本目に **誰でも知っている物での例え**（台所・食べ物・スポーツ・日用品）。専門分野の例えは禁止。
- 章の中盤に1回、**進捗の承認**（「ここまでついてこられていますわね」）。
- 章の中で1回、**視聴者の行動への敬意**（「毎日そばで見ているのはあなただけ」）。
- 章末 `summary` の最後に「ここまで見たあなたは、もう◯◯できるレベル」と到達点を言語化。
- 最終章の最後の実践は「これだけ」に絞り、残りを **次回の引き** にする（マダンテ禁止）。

### ending（エンディング）8本
- `osarai_intro`: 「ここまで見続けたあなたへ」で開始。
- `osarai_*`: 本編の例え（スポンジ・ストロー等）を短く再登場させて記憶に結ぶ。
- `thanks`: 開いた→最後まで見た→明日の現場での行動、の3段で行動を褒める。
- `cta`: 登録＝「困ったときすぐ戻れる」、高評価＝「同じ悩みの仲間に届く」。キャラの軽口はその後ろ。
- `close`: 次回予告を1文。「あなたを待っている」で閉じる。

## 4. プロンプト追記ブロック（生成LLMにそのまま渡す）

```
【視聴者心理の設計ルール（必須）】
- 視聴者は介護職。忙しい合間にこの動画を開いた人。あなたはその人が大好きで、一対一で話す。
- tsukami_01 の第一声は「動画を開いた／調べに来た」という視聴者の行動を1文で承認してから、衝撃の一言に入る。承認は1文・3秒以内。
- 褒めるのは必ず具体的な行動（開いた、見続けた、記録している、気づいた、明日現場で見る）。性格や才能は褒めない。「あなたは素晴らしい」のような抽象的な褒めは禁止。
- 褒めは全編で4〜5回まで。各章に敬意1回、章末summaryに「ここまで見たあなたは、もう◯◯できる」を1回。
- 例え話は誰でも知っている物だけ（台所用品、食べ物、スポーツ、日用品）。1シーンに1つ。専門分野や趣味に依存する例えは禁止。
- tsukami_03 で予告した「たった1つ」は、最終章の末尾で必ず回収する。回収できない予告は書かない。
- 最終章の最後の実践は要点を「これだけ」に絞り、詳しい話は「次回まるごと一本」と引きに回す。全情報を出し切らない。
- ending_cta の登録・高評価の理由は視聴者の利益（困ったときすぐ戻れる、同じ悩みの仲間に届く）で書き、キャラの軽口はその後ろに添える。
- ending_close は次回予告1文＋「あなたを待っている」で閉じる。
- 医学的な事実・数値は変えない。心理要素は言い回しにのみ適用する。
```
