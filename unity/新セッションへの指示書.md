## あなた（Unity操作Claude）へのお願い

Unity上で、下記のスクリプト1個だけで動く3D RPGデモ（草原マップ＋クエスト）を、
**Unityに入れて再生（Play）まで**持っていってください。難しい追加実装は不要です。

### 前提
- レンダーパイプライン：**URP**
- スクリプトは1ファイル完結（外部アセット不要で表示されます）
- スクリプト本体の入手：
  - GitHub リポジトリ `kazuki1220png/hepatitis-presentation`
  - ブランチ `claude/rpg-design-doc-structure-rjjznj`
  - パス `unity/DokukeshiQuest.cs`
  - （アクセスできなければ、ユーザーが `DokukeshiQuest.cs` を直接渡します）

### 手順
1. `DokukeshiQuest.cs` を Unity プロジェクトの **Assets フォルダに配置**する
   （★ファイル名とクラス名は必ず `DokukeshiQuest`。変えないこと）
2. コンパイルが通るのを確認（エラーが出たら内容を報告）
3. Hierarchy に**空の GameObject**を1つ作り、名前を「Game」にする
4. その GameObject に `DokukeshiQuest` コンポーネントを**アタッチ**
5. Inspector で **`Generate Grassland` を ON（チェック）**にする
6. `Edit > Project Settings > Player > Active Input Handling` が
   **「Both」**であることを確認（違えば Both に変更）
7. **Play（▶）** を押して再生する

### 成功の状態（これが出れば完成）
- 起伏のある**緑の草原**が広がり、木と花が点在
- 黄色いキャラが草原の上を歩ける（**W/S 前後・A/D 旋回・E 話す/調べる**）
- 村人マレンに話す → 北の洞口に入ると洞窟に切替 → 光る毒消し草を採取 → 村へ戻って渡すと「クエスト達成！」

### 終わったら
- 動いたら**スクリーンショット**か画面の様子を報告してください
- エラーやうまく出ない点があれば、その内容を報告してください

## 次の段階（動いたら／任意）

見た目をもっと良くする番。以下はユーザーと相談しながら:

- **Gaiaの地形に載せる**：Gaiaで草原/森の地形(Unity Terrain)を作り、`DokukeshiQuest`の
  Inspectorで `Use Gaia Terrain` を ON、`Generate Grassland` を OFF にして再生。
  → コード生成の仮草原が、Gaiaの本番地形に置き換わる（キャラはそのまま地形上を歩く）。
- **キャラを差し替える**：`Player Model` 枠に、用意した3Dキャラ（Meshy等）のPrefabをドラッグ。
  `Npc Model` `Herb Model` も同様に差し替え可能。
