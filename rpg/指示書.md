# 指示書（次に作業する人／モデルへ）

## この指示書のゴール

**「盗賊退治の3DフィールドのRPG作って」の一行だけで、RPGの"最小枠（1アーク）"が作れる**状態にする。
そのために、毎回変わらない「生産の仕組み」を固定し、**お題（テーマ）だけを差し替えられる**ようにする。

### 全体の考え方：最小枠 → 積み上げて1本に

- 一行のお題 = **最小枠1つ**（例：盗賊退治 ＝ 第1アーク）。フィールド＋敵＋首領＋戦闘＋BGMが一通り動く、遊べる最小単位。
- その最小枠が**良い精度で出せる**ようになったら、同じパイプラインで**続きの物語（第2・第3アーク…）を足す**。
- アークを積み上げると**1本のRPG**になる。だから狙うのは「1アークを高品質で量産できる仕組み」。

作業モデルはClaude／GPT系どちらでも可。まず [00_根本企画書.md](./00_根本企画書.md)・
[README.md](./README.md)・[生産パイプライン.md](./生産パイプライン.md) を開いてから始める。

## 一行のお題を展開する手順

1. お題を**ジャンルの型**に当てはめる（下の「退治もの」テンプレ参照）。
2. 型から各班ファイル（UI/マップ/バトル/シナリオ/システム）へ落とす。
3. [生産パイプライン.md](./生産パイプライン.md) の手順で、フィールド生成・素材配置・BGM生成を回す。
4. 実機で確認 → 詰まった点を各班ファイルと**この指示書に反映**（build → fix → 指示書更新のループ）。

### ジャンルの型：「〇〇退治」もの（再利用可）

| 要素 | 中身 | 担当班 |
|------|------|--------|
| 討伐対象 | 誰を退治するか（例：盗賊団） | シナリオ |
| 脅威 | なぜ退治が必要か（村・街道が襲われている等） | シナリオ |
| 敵拠点 | アジト＝マップの最終エリア | マップ |
| 首領（ボス） | 最終戦の相手 | バトル |
| 段階的な強敵 | 雑魚→幹部→首領 の難易度カーブ | バトル / システム |
| 依頼者・動機 | 主人公が退治に向かう理由 | シナリオ |

## 最小枠の「合格」チェックリスト（品質ゲート）

一行お題で出した最小枠が、**続きを足してよい品質か**を判定する基準。
ここが全部○になったら「精度OK」＝次のアークへ進む合図。

- [ ] 3Dフィールドを1エリア、実際に歩ける
- [ ] 雑魚敵と戦える（エンカウント → 戦闘 → 勝敗）
- [ ] 首領（ボス）戦がある
- [ ] バトルBGMが鳴る
- [ ] 勝ち／負けの結果が処理される
- [ ] セーブ／ロードが効く
- [ ] コアループ（[00_根本企画書.md](./00_根本企画書.md)）が体感できる

△が残るなら、その項目を該当班ファイルの未決事項に落として先に潰す。

## 続きの物語（次アーク）の足し方

最小枠が合格したら、**同じ生産パイプラインでお題だけ差し替えて**次を足す。
アークをまたいで**引き継ぐもの**を壊さないのが積み上げのコツ:

- 引き継ぐ（共有）：世界観・[90_用語集・共通ルール.md](./90_用語集・共通ルール.md)・セーブデータ・主人公の成長・生産パイプライン
- 差し替える（アーク固有）：討伐対象／舞台エリア／首領／BGMの雰囲気／物語

手順：新しいお題を「お題の記入欄」に書く → 「退治もの」等の型に当てはめる → 各班へ展開 →
[生産パイプライン.md](./生産パイプライン.md) で生成 → 合格チェック。前アークとの繋ぎは
[40_シナリオ班.md](./40_シナリオ班.md) の章立てで管理する。
