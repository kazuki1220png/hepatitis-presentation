# RPG企画書 — 進め方

Claudeが1ファイルを肥大化させがちなので、**中心の「根本企画書」＋班ごとの分割ファイル**という構成にしています。

## 構成

```
rpg/
├── 00_根本企画書.md          ← 中心。世界観・コアループ・柱だけ。ここは薄く保つ
├── 10_UI班.md
├── 20_マップ班.md
├── 30_バトル班.md
├── 40_シナリオ班.md          ← 推奨追加（不要なら削除可）
├── 50_システム・データ班.md   ← 推奨追加（不要なら削除可）
└── 90_用語集・共通ルール.md   ← 全班が参照する単一の真実
```

## 使い方（Claudeへの頼み方の例）

- 「**バトル班のファイルだけ**直して。戦闘方式をコマンド制で詰めて」
  → 他の班に触らず作業できる（分割の利点）
- 「UI班とバトル班の**接続（インターフェース）**が噛み合ってるか確認して」
- 「**根本企画書の柱**を3つ決めたい。壁打ちして」

## 大事なルール（破綻防止）

1. **接続（インターフェース）**を変えるときは、相手の班ファイルも同時に直す。
2. 用語や単位は必ず [90_用語集・共通ルール.md](./90_用語集・共通ルール.md) を先に更新。
3. `00_根本企画書.md` は「薄い中心」に保つ。厚くなったら各班へ移す。

## 各ファイル共通のテンプレ

- **決定事項**（決まったことだけ簡潔に）
- **他班との接続**（班をまたぐ約束事）
- **未決事項 / TODO**（次に決めること）
